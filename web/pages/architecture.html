How apexFMP works

apexFMP organizes the application around a small set of clear contracts. FileMaker owns the system of record, and the interface is built as HTML templates. Those templates are hydrated using FQL-generated JSON data, then rendered in a FileMaker web viewer.

Flow

  1. Build a template in HTML, CSS, and JavaScript
  2. Define merge variables and their FQL data sources
  3. Resolve those variables in FileMaker
  4. Convert data to JSON for the browser
  5. Render the page in the web viewer
  6. Send actions back through the FileMaker script bridge

Core technologies

  • FQL for precise data retrieval
  • JSON for passing structured data between FileMaker and the browser
  • Set Field By Name for dynamic payload handling
  • Evaluate for dynamic logic and metadata-driven behavior
  • Perform JavaScript in web viewer for interaction and UI updates
  • Web viewer as the rendering surface
